# STARFALL

自分のペースで宇宙船を育てる、ブラウザ向け放置シューティングの試作です。装備の回収・選択・強化でビルドを組み、1画面の戦闘を楽しめます。広告や課金はありません。

## 遊ぶ

[ブラウザで遊ぶ](https://guhehep.github.io/starfall-idle-shooter/)。進捗はブラウザに自動保存され、公開版とローカル版では別々に保管されます。

ローカルで起動する場合：

```powershell
npm ci
npm run dev
```

ターミナルに表示されたローカルURLをブラウザで開きます。

- 自動操縦と自動射撃は最初から有効。敵から装備を回収し、右のドックで組み替えます。
- WASD・矢印キー、または戦闘画面のドラッグで移動。操作をやめると自動操縦に戻ります。
- Space、またはOVERDRIVEボタンで基本5秒間の火力増幅と敵弾消去。使用後はクールダウンします。永続研究で持続時間と待機時間を改善できます。
- 5ウェーブごとにボス。撃墜・時間切れは3秒後に再出撃し、獲得CRは保持します。
- 武器はパルス・スプレッド・ランス・ミサイル・アーク・オービットの6系統。進んだ宙域ほど回収候補が増えます。通常敵の装備回収率は宙域に応じて変化し、ボスは武器とパーツをそれぞれレア以上で確定ドロップ。WAVE 15クリアで再出撃と永久研究を解放します。
- オービットは八枚の花弁状結晶を上方向の扇形に放ち、緩やかに敵を追尾します。パルスの二連射、スプレッドの散弾、ランスの貫通、ミサイルの誘導と爆風、アークの電撃連鎖と、攻撃の形と役割を分けています。
- 装備・倉庫タブから装備倉庫を開き、武器・ウィング・ボディ・支援ドローンをそれぞれ任意に装備できます。取得時の自動装備はありません。各装備にレア度・アイテムLv・品質とランダムな副次効果があり、装備選びを成長の中心にしています。
- ウィングは照準・速度・導流、ボディは重装・高出力・吸収、ドローンは攻撃・凍結・回復の3モデルずつ。品質は基本能力に影響し、モデルの違いは機体のシルエット・コア・支援機と射撃の外観に反映されます。
- 凍結と減速中の敵への追加ダメージ、回復と高シールド時の火力、会心率と会心倍率、範囲拡張と爆風・連鎖など、戦闘効果の組み合わせでビルドが生まれます。装備画面と倉庫で現在の組み合わせを確認できます。
- 「組み合わせ」の「構成」には、名前付きで3組の装備を保存できます。武器・ウィング・ボディ・ドローンの4部位とモジュールをまとめて呼び出し、保存・呼び出しにCRは使いません。名前は20文字まで。保存済みの構成は内容を確認して上書き・削除できます。
- 呼び出しは4部位の所持と部位の一致、モジュールの解放をすべて確認してから一度に適用します。HPの割合、次の主武装・ドローン射撃までの待ち時間、発動中の必殺技と待ち時間、吸収の回復予算は維持し、飛翔中の弾も残ります。構成は装備IDを参照するだけで、装備品を複製しません。再出撃後も保存されます。
- 「装備の相性」は未成立・相性成立／待機・発動中を表示します。凍結追撃は減速中の敵数、高シールド維持はシールド70%の条件も確認できます。表示は既存の戦闘効果から算出します。
- 副次効果は威力・連射・会心・貫通・誘導・爆風・電撃連鎖・凍結減速・シールド吸収・撃墜CRの10種類。系統固有の攻撃と組み合わせて戦闘に反映されます。倉庫の推定DPSは全弾命中時の目安で、爆風・連鎖などの追加命中は含みません。
- パーツの副次効果は全武装威力・連射・会心・シールド・再生・軽減・効果範囲・減速中の敵への威力・必殺技の待ち時間・吸収・撃墜CRの11種類。基本能力と副次効果を倉庫で個別に比較できます。
- 倉庫は武器64個とパーツ64個まで保管。名前・能力の検索、装備中・保護中・売却可能の絞り込み、部位・レア度・武器系統の絞り込み、並び替え、性能比較に対応します。検索は装備名だけでなく、モデルの説明と副次効果も対象です。
- 倉庫一覧は小さな装備アイコンのグリッドです。レア度は枠の色、装備中はチェック、保護は鍵で示し、文字は拾得Lvと強化値だけに絞っています。全アイテムをスクロールで見渡せ、選ぶと名前・性能・副次効果を全文で確認できます。詳細から戻ると一覧の位置を保ちます。キーボードでは矢印で移動、Enter・Spaceで詳細を開きます。
- 装備アイコンは15モデル共通の金属の陰影と反射、モデルごとの発光色で描いています。倉庫は深いネイビーの素材感に細いレア度の光を合わせ、装備中と保護中は両方のマークを表示します。
- 装備の詳細は「性能・強化・相性」の3タブです。性能には主要数値・交換時の差分・固有効果・全副次効果をまとめ、選択品と現在品の両方で0の項目だけを省きます。強化費・次段階・同じ強化段階での比較と還元は強化タブ、現在の構成の成立条件は相性タブで確認できます。通常の説明を一画面に収め、長い名前や大量の条件がある場合は全文をスクロールで読めます。名前・タブ・操作は固定し、タブを切り替えても各画面の位置を保ちます。
- 装備候補は主要性能を「装備中 → 候補」と差分で示します。割合の増減はポイント（pt）表示です。副次効果は追加・上昇・低下・失う効果を色と文字で区別し、変わらない効果だけ折りたたみます。吸収などの小数値を整数に丸めず、武器固有の追尾・爆風・連鎖・貫通も考慮して維持される能力を示します。武器DPSは主弾と会心の目安、パーツ数値は固有性能で、副次効果は別欄で比較します。
- 取得時の自動売却は初期状態でOFF。指定したレア度以下の今後の取得装備をCRに換えます。倉庫内の装備は個別売却、または対象件数と売却額を確認してから一括整理できます。自動売却・詳細な絞り込みは折りたたみ内にまとめています。
- 装備中・保護中・初期装備は売却対象から除外されます。満杯時も保護装備を自動で削除することはありません。
- 保存構成が参照する装備も、一括整理と倉庫満杯時の自動整理から除外します。倉庫に使用している構成名を表示し、個別売却では影響する構成を確認してから売却できます。売却後は構成を欠品状態として保管し、呼び出しを停止します。
- 倉庫で装備中の品を選ぶと、CRで強化できます。武器・ウィング・ボディ・支援ドローンそれぞれ+10まで。1段階ごとに基本性能を5%伸ばし、拾得Lv・品質・副次効果は維持します。強化費は拾得Lv・レア度・現在の強化段階に応じて上昇し、装備変更や再出撃後も強化は品に残ります。強化ボタンと費用は比較情報のスクロール領域から分離し、次段階の性能を確認して操作できます。未装備品は同じ強化段階まで育てた場合の性能と追加費用も比較できます。売却できる装備は、通常の売却額にそれまでの強化費の50%を加えて回収します。強化費と研究価格は維持し、より良い装備への再投資を助けます。
- 研究タブのCRスキルツリーは攻撃・防御・運用の3系統、計9スキル・各3ランク。最高クリアWAVE 15・20・25と前提スキルで段階を解放します。与ダメージ・会心・凍結追撃、シールド・自己修復・高シールド時の火力、CR回収・必殺技の冷却・持続時間を伸ばせます。取得した研究は永続です。
- 永続研究は装備強化と投資先を選ぶための価格です。初回は基礎3〜4万CR・中段10〜12万CR・上段30〜36万CR、同じスキルの次ランクは3倍の費用。例えば出力制御ランク2と照準解析ランク1で24万CRを使います。全27ランクの取得には計1,852.5万CRが必要で、長期の育成目標です。取得済みランクは価格改定後も保持します。
- CRでの機体調整は出力・連射・装甲の3項目、各10段階までの小さな補助です。ドローンは回収した装備で変更します。以前のセーブの強化投資は新しい調整分との差額を一度だけCRに還元します。
- 機体モジュールはWAVE 3で強襲型、6で防衛型、8で回収型が解放されます。
- 武器での撃破は熟練ポイントを獲得します。通常敵1、ボス5ポイント。30・100・250・500ポイントで熟練度が上がり、威力が最大40%増加。ドローンの撃破は対象外です。熟練度は帰還後も残ります。
- Iで装備倉庫、Mで任務、Pで一時停止。Escでメニューを閉じます。入力欄ではショートカットを無効にします。遊び方・サウンド・演出設定は画面上のボタンから変更できます。
- 倉庫の検索は×で消去でき、現在の絞り込みは設定を閉じても表示します。「解除」は検索条件だけを戻し、自動売却設定を保持します。スマートフォンでは装備を選ぶと比較を拡大し、「装備一覧に戻る」で選び直せます。
- スマートフォンでは戦闘画面を中心に、下部の「倉庫・整備・研究・記録」から各画面を開きます。整備は必要なときだけ開くシートで、メニュー中は戦闘を停止します。縦向きの任務は一覧から選択すると詳細・報酬の画面へ切り替わり、操作ボタンをスクロール領域の外に保ちます。タッチの移動は相対ドラッグで、指を置いた場所へ機体が移動することはありません。
- 機体の表示倍率が0.7未満の小画面では、自機・機体パーツ・通常敵・精鋭・旗艦の細かな反射線やベントを整理した描画へ切り替えます。輪郭・武器・発光コアは維持し、画面を広げると細部を持つ描画へ戻ります。高密度画面は最大2倍・300万ピクセルまで描画を増やし、画面上の機体サイズと移動・当たり判定は維持します。
- 装備名は省略記号で切らず、折り返して表示します。ドックは図・名前・Lv・強化値の横長リストで、必要な場合は装備欄の中だけをスクロールします。詳しい能力は倉庫で全文を読めます。レア度は装備の枠・光・小さな印の色で示し、名称はツールチップと遊び方で確認できます。
- ドックの任務ボタンで受注中の任務を開けます。保留中の報酬があれば受領画面を優先します。任務の受注・受領操作と満杯などの理由は、詳細をスクロールしても見える位置に置いています。

### 任務・特注装備・航行作戦

航行記録の「任務」で12種類の繰り返し任務を受注できます。通常撃破・精鋭・旗艦・WAVEクリア・凍結中の敵・高シールドでの撃破、武器6系統の実戦が目標です。受注中の1件だけ実戦で進み、切り替えても各進捗を保管。ランクは10まで上がり、最終ランクも反復できます。

達成した任務は、武器6系統とパーツ9モデルから好きなモデルを選んで報酬を受領します。相性のよい副次効果1つを保証し、残りはランダムです。最初の5回はエピック、5回完了後のRank 6からレジェンダリー。対象倉庫に空き枠が必要で、満杯でも達成を失いません。報酬は保護状態で保管され、自動売却対象外・換装は手動です。

航行情報では「巡航」「精鋭掃討」「危険宙域」の3作戦を選べます。掃討はWAVE30、危険はWAVE50クリアで解放。敵HPと精鋭・射撃が強まる代わりに、戦闘CRと通常敵の回収率が上がります。変更は次の戦闘開始から（再挑戦・再読込を含む）。離席CRと売却額には作戦倍率を掛けません。

収集目標は全22件。精鋭・旗艦・装備の累計取得とWAVE200までの目標を追加しました。任務と作戦は再読込・再出撃で保持し、既存セーブの装備と研究も引き継ぎます。詳細は[やり込み設計](docs/progression-design.md)を参照してください。

### 中盤以降の研究と装備更新

出力制御は1ランクごとに与ダメージ+6%。照準解析は会心率+2%に会心倍率+0.12倍を加え、会心率が上限でも効果を持ちます。凍結追撃の8%と安定出力の4%は、装備の対応効果に乗算して増幅します。自己修復は1ランクごとに最大シールドの0.2%を毎秒回復し、最低0.6HP/秒を保証します。価格・3ランク上限・研究の前提は維持し、全27ランクの総額は18,525,000CRです。

敵の耐久曲線と装備の通常回収は維持しています。自然進行を60分ずつ比較し、実UIで交換・強化・売却・研究を確認しています。研究効果と強化費の還元は `tests/mid-growth.test.ts` で検証します。

### 序盤の装備と育成

最初の出撃ではWAVE 1の初回クリアで武器、WAVE 2でパーツを回収します。いずれもアンコモン以上でランダムな副次効果を持ち、倉庫から任意に装備します。再クリア・再出撃では再配布しません。自動売却設定はこの報酬にも適用します。

通常敵の回収率はWAVE 1〜15では宙域の基準値の半分、WAVE 16〜30で段階的に通常値へ戻ります。ボスと精鋭の確定回収は維持します。初期90CRで初期武器の+1（88CR）を試せ、拾った装備の強化も通常の戦闘収入で選べます。倉庫を開くと戦闘は一時停止します。

初期状態の成長テンポは自然進行の計測とブラウザで確認しています。初回報酬と序盤の回収率は `tests/early-progression.test.ts` で検証します。

### 宙域と精鋭

現在のWAVEに応じて5つの宙域を進みます。「記録」の航行情報で現在の補正と次の宙域を確認できます。以下の敵弾速・射撃間隔は敵に対する補正で、CR倍率は戦闘報酬と離席回収に反映されます。装備の売却額には掛かりません。

| 宙域 | 開始WAVE | 敵弾速 | 敵射撃間隔 | CR倍率 | 通常敵の武器 / パーツ回収率（基準値） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 巡航宙域 | 1 | ×1.00 | ×1.00 | ×1.00 | 12% / 14% |
| イオン星雲 | 15 | ×0.90 | ×1.05 | ×1.06 | 13% / 15% |
| 残骸回廊 | 30 | ×1.00 | ×1.12 | ×1.15 | 16% / 18% |
| 極光前線 | 50 | ×0.85 | ×0.90 | ×1.25 | 18% / 20% |
| 虚空宙域 | 75 | ×1.08 | ×1.04 | ×1.40 | 20% / 22% |

WAVE 20以降は各WAVEに精鋭が1機出現します。ヴァンガードは予告後の三方向射撃、スナイパーは予告中に照準を固定した高速弾、バラージは六方向の弾幕を使います。輪郭・名称・射撃予告で見分けられ、撃破すると武器またはパーツのどちらか1個をレア以上で必ず回収できます。ボスは扇状・旋回・交差の3パターンが順番に出現し、HPが半分になると第2形態へ移ります。

3種類のボスは、それぞれ異なる機体の輪郭を持ちます。各機に2形態、計6枚のテクスチャを用意し、第2形態では装甲とコアの見た目も変わります。

| 旗艦 | 攻撃パターン | 機体の造形 |
| --- | --- | --- |
| WARDEN | 扇状 | 後退角の付いた幅広い肩と琥珀色の砲口 |
| HELIX | 旋回 | 紫の環状リアクターと3枚の曲がった刃 |
| BASTION | 交差 | 4枚の厚い装甲と緑の十字形の動力部 |

凍結追撃の追加ダメージが実際に乗った命中には氷片を描き、電撃連鎖には到達点の小さな菱形を添えます。高シールド時の火力強化は機体の金色の輪で示し、その条件で撃った弾には金色の細い光を残します。飛翔中の弾は、装備を替えても射撃時の状態を維持します。

### 進捗リセット

設定の「リセット内容を確認」から、確認欄に「リセット」と入力して実行できます。WAVE1・初期装備・90CRから再開し、装備と強化、研究、熟練度、記録、任務、保存構成、補助調整、自動売却などの進捗を初期化します。ゲーム内で元に戻せません。サウンドとエフェクト設定は引き継ぎます。

新しい保存先を準備してから有効な保存先を切り替え、失敗時は現在の進捗を保持します。別タブの古い自動保存は有効な進捗を上書きできません。リセットは通常の再出撃とは別の操作です。

### 回復・セーブ・離席

ダメージによるシールド吸収は、主武装・支援ドローン・副次攻撃で共通の回復予算を使います。予算の容量は最大シールドの3%、毎秒同じ量を補充します。実際に回復した量だけ消費し、装備交換で補充されることはありません。自然再生とメンダードローンの継続回復は別枠です。

セーブは同じブラウザ・同じURLのlocalStorageへ自動保存します。離席が60秒以上なら、最高クリアWAVEに基づくCRを最大8時間分受け取ります。離席回収は従来の基準式に3倍の固定倍率を掛け、最高クリアWAVEの宙域・回収型モジュール・装備・回収研究の補正も反映します。閉じている間にWAVEは進まず、装備も増えません。音は初期状態でOFFです。

## 狙い

**手軽さ**：自動戦闘・自動復帰で、短時間に強化を選ぶだけでも遊べます。

**爽快感**：武器ごとの弾形・光跡・命中、爆発、必殺技、装備とドローンの変化で、育成を戦闘の変化として見せます。背景は中央を暗く保ち、敵弾と射撃予告を読み取れるようにしています。

**ゲーム性**：6系統の武器と3部位の装備、それぞれの副次効果を組み合わせ、移動と必殺技で突破を助けます。

**やりこみ**：回収装備の選択・育成、スキルツリー、図鑑と達成報酬を通してビルドを伸ばし、先の宙域を攻略します。再出撃は今回クリアしたWAVEに応じてCRを獲得し、現在のWAVEと補助調整をリセットします。所持CR・装備と強化段階・保護と自動売却設定・熟練度・永久研究・最高記録・図鑑・保存構成は残ります。

### ホーム画面への追加とオフライン起動

設定の「ホーム画面で遊ぶ」からインストール、または追加方法を確認できます。対応ブラウザでは専用アイコンで起動し、standalone表示で遊べます。iPhone・iPadでは共有メニューの「ホーム画面に追加」を使い、見つからない場合はSafariで開きます。

初回はオンラインでゲーム本体・背景・アイコンの取得が必要です。全ファイルの保存を確認した場合だけ「オフラインで起動できます」と表示します。準備完了後は通信がなくても起動でき、進捗は端末内に保存します。ブラウザが保存領域を消去した場合は再取得が必要です。

新しい版はプレイ中に自動で再読み込みせず、ゲームをすべて閉じて次に開いたときに適用します。キャッシュは公開パスごとに分離し、別のゲームや進捗の保存には触れません。開発モードはキャッシュせず、`npm run build` と `npm run preview` でPWAを検証します。

### GitHub Pagesへの公開

`main` へのpushで、GitHub Actionsがテスト・ビルドを実行し、成功した場合に `dist/` をGitHub Pagesへ公開します。手動実行も可能です。リポジトリの **Settings → Pages → Source** は **GitHub Actions** を選びます。

Viteの相対baseと背景画像の `BASE_URL` 対応により、リポジトリ名を含む公開パスでも動作します。Node.js 22を使用します。ローカルの依存関係・ビルド成果物・プレイテストの生成物はGitに含めません。

Phaser + TypeScript + Vite。主な責務を次のファイルに分けています。

| ファイル | 役割 |
| --- | --- |
| `src/game/simulation.ts` | 戦闘・装備・育成・セーブの規則 |
| `src/game/scene.ts` | 入力、機体・敵・弾・射撃予告、描画の統合 |
| `src/game/combat-visuals.ts` | 武器の光跡、砲口・命中・会心・撃破の光 |
| `src/game/boss-visuals.ts` | 3旗艦×2形態のテクスチャと発光コアの位置 |
| `src/game/environment-visuals.ts` | 宙域の淡い光と背景の補助描画 |
| `src/game/visual-assets.ts` | 背景画像と宙域の対応、読み込み定義 |
| `src/game/sectors.ts` / `src/game/collection.ts` | 宙域・精鋭・後半のHP曲線 / 図鑑・達成目標 |
| `src/game/loadouts.ts` | 保存構成のID参照、検証、欠品と使用状態の判定 |

機体はCanvasで生成したテクスチャとPhaserの描画を組み合わせ、効果音はWeb Audioで合成します。ビジュアルの方針は[ビジュアル設計](docs/visual-design.md)にまとめています。

### 背景アセット

宇宙背景はImageGenの組み込みツールで生成した1536×1024のPNGです。既存の星雲に3枚を追加し、宙域に応じて画像を切り替えます。明るいランドマークは上部・周辺に寄せ、中央と下部に戦闘用の暗い余白を残しています。

| 使用する宙域 | 画像 | 生成記録 |
| --- | --- | --- |
| 巡航宙域・イオン星雲 | `public/assets/nebula-v2.png` | `nebula-v2.prompt.json` |
| 残骸回廊 | `public/assets/sector-wreckage-v1.png` | `sector-wreckage-v1.prompt.json` |
| 極光前線 | `public/assets/sector-aurora-v1.png` | `sector-aurora-v1.prompt.json` |
| 虚空宙域 | `public/assets/sector-void-v1.png` | `sector-void-v1.prompt.json` |

生成記録は各PNGと同じフォルダーにあり、完全なプロンプト、生成ツール、元ファイル、生成日、寸法、透明背景の指定を保存しています。新しい3枚には目視確認の記録も含めています。描画では画像の縦横比を保って戦闘画面を覆い、画像内のランドマークに重なる追加の構造物描画は抑えています。

### バランスと移行

機体モジュールは攻撃力・耐久力・報酬のトレードオフを持ち、武器とパーツに組み合わせられます。敵HPは初動に2.4倍の補正を掛け、WAVE 30まで滑らかに通常値へ戻します。その後はWAVE比の3.5乗で成長します。後半を装備の更新・効果の組み合わせ・操作で攻略できるようにする調整です。

既存のv1セーブは進行・武器・熟練度を保持し、新しい装備部位の初期品と強化投資の還元を補完して読み込みます。旧研究は対応する新スキルへ移行し、未使用コアと移行上限を超える研究投資を一度だけCRへ還元します。図鑑のない旧セーブは、現在保管している初期品以外の装備から発見記録を補完します。

現在は遊べる試作です。長時間の成長速度、後半の難易度、研究の価格は、プレイ感に合わせて調整する前提です。
