# 装備を集め続けるための任務と作戦

成長の中心を装備の取得・比較・組み合わせに置く。任務は狙う装備を選ぶための入口、作戦は手持ちのビルドで難度と回収量を選ぶ入口にする。通常の巡航は従来どおりで、追加の難度はプレイヤーが選ぶ。

## 12種類の繰り返し任務

航行記録の「任務」で1件を受注する。受注中だけ実戦の撃破・クリアを数える。任務の切り替えで途中の進捗は失わず、達成済みの保留任務も受領できる。受領した任務だけ次ランクの進捗が0に戻る。現在受注中の任務は維持する。

| 任務 | Rank 1の目標 | 解放する最高クリアWAVE |
| --- | --- | ---: |
| 前線制圧 | 通常敵120機（精鋭・旗艦を除く） | 15 |
| 精鋭討伐 | 精鋭5機 | 20 |
| 旗艦追撃 | 旗艦3機 | 15 |
| 航路開拓 | WAVEクリア8回 | 15 |
| 凍結包囲 | すでに凍結中の敵30機 | 20 |
| 安定戦線 | シールド70%以上で80機撃破 | 20 |
| パルス・スプレッド・ランス実戦 | 各系統の主武装で60機 | 15 |
| ミサイル・アーク実戦 | 各系統の主武装で60機 | 20 |
| オービット実戦 | 主武装で60機 | 30 |

武器実戦はドローンを除き、弾を発射した武器へ帰属する。換装前に飛ばした弾、貫通・爆風・電撃の追加撃破も同じ帰属で、同一の敵を重複加算しない。凍結包囲は致死弾で初めて凍結させた敵を除く。安定戦線は致死ダメージを与える前のシールド率で判定し、その命中の吸収回復で条件を満たす場合は数えない。

ランクは最大10。目標は `基礎目標 + ceil(基礎目標 × 0.2) × (Rank−1)`。Rank 10も反復できる。完了回数・各任務の進捗・受注中の任務は保存し、再読込・再出撃で維持する。過去の撃破と離席時間では任務は進まない。達成中は進捗を目標値で止め、報酬の自動受領は行わない。

## 15モデルの特注装備報酬

受領時に武器6系統またはパーツ9モデルを選ぶ。モデルと相性のよい副次効果1つを保証し、残りは通常装備の副次効果プールから重複なしで抽選する。品質・基本性能・支援機数・強化・売却は通常装備の規則と同じで、隠れた固有倍率は追加しない。

| モデル | 保証する副次効果 |
| --- | --- |
| パルス / フォーカスウイング / ストライカードローン | 会心率 |
| スプレッド | 爆風 |
| ランス / アーク | 凍結減速 |
| ミサイル / サイフォンフレーム | シールド吸収 |
| オービット | 電撃連鎖 |
| ベロシティウイング | 連射速度 |
| カスケードウイング | 爆風・連鎖範囲 |
| バスティオン装甲 / メンダードローン | シールド再生 |
| リアクターコア | 全武装威力 |
| フロストドローン | 減速中の敵への威力 |

保証値は通常範囲の中央値から75%位置までの抽選。最初の5回はエピック（副次3枠）、5回完了後のRank 6からレジェンダリー（副次4枠）。拾得Lvは `最高クリアWAVE + 2 × (Rank−1)`、最大10000。到達記録が上がると次の受領品の水準も上がる。

対象倉庫の空き枠1つを受領前に確認する。満杯時は進捗・完了回数・装備ID・乱数を消費しない。受領品は保護状態で保管し、自動売却の対象外。自動換装はしない。実際に取得した品を収集記録へ加算し、同じ達成を再受領できない。報酬を保持したい場合は初期保護を維持し、通常の倉庫操作で比較・強化できる。

## 航行作戦

航行情報で作戦を選ぶ。選択中と現在の戦闘に適用中の作戦を別に表示する。変更は次の戦闘開始時（次WAVE・再挑戦・再読込）に適用し、進行中の敵HP・射撃・報酬倍率を途中で変更しない。

| 作戦 | 解放WAVE | 敵HP | 追加精鋭 | 敵弾速 | 敵射撃間隔 | 戦闘CR | 通常敵の各装備回収率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 巡航 | 初期 | ×1.00 | 0 | ×1.00 | ×1.00 | ×1.00 | 変更なし |
| 精鋭掃討 | 30 | ×1.20 | +1 | ×1.00 | ×0.94 | ×1.25 | +4ポイント |
| 危険宙域 | 50 | ×1.50 | +2 | ×1.10 | ×0.90 | ×1.55 | +8ポイント |

補正は宙域補正へ加わる。追加精鋭は既存の通常敵を昇格させ、敵数の上限を増やさない。通常WAVE 20以降の精鋭は巡航1機・掃討2機・危険3機。追加の精鋭も既存の射撃予告とレア以上の回収規則を持つ。離席CRと装備売却額には作戦倍率を掛けない。

## 長期の収集目標

従来8目標を保持し、精鋭100/500機、旗艦25/100機、エピック100個、レジェンダリー10/50個、武器とパーツ各100/500個、WAVE75/150/200の14目標を追加する。全22目標。追加目標のCR報酬合計は376,500。達成時に一度だけ自動受領し、既存記録で満たす目標も一度だけ補完する。研究価格を変えず、装備集めの経過を長期目標として残す。

任務と作戦は `missions.ts` / `operations.ts`、特注報酬は `requisition.ts`、撃破・受領・保存の統合は `simulation.ts`、記録画面は `ui.ts` が担当する。利用者の進行を変更する操作の検証は保存先を持たない専用fixtureで行う。
